## 关于异步

12d 与 13 所在的段落要等定时器，所以整体跑在一个 `async` IIFE 里。
发牌动画、`async persist()` 都靠 `await wait(...)` 让出事件循环（保存后立刻读 `localStorage` 会拿到旧值是踩过的坑）。

## jsdom 缺的三样（文件开头补了 shim）

- `setPointerCapture` / `hasPointerCapture` / `releasePointerCapture` —— 不补的话「用手拖牌」
  这条路在走查里完全测不到（`bindCardPointer` 会直接 return）。
- 拖动中读位置要记得：牌是走 **transform** 的，`style.left/top` 还是原值（辅助那组踩过）。

## 测试钩子

生产代码里以**下划线结尾**的导出都是给走查用的只读钩子，不许在 App 里调用：

- `Table.trayOpen_()` / `Table.trayClose()`：直接开关选牌台，跳过动画与定时器；
- `Table.snapshot_()`：当前会话快照（桌面牌数、牌堆、已抽 id），**外加 `cam`**（镜头 `x/y/scale`）—— 12d 要靠它量平移量。
- `Library._dropIndex(rects, x, y)`：拖拽落点索引（纯函数）。
- `Table.placeCard_(i, x, y)`：把某张牌直接摆到世界坐标 —— 造「歪牌阵」用。辅助开着时拖出来的永远是齐的，歪的阵造不出来。
